# Sales-Dashboard
Develop an interactive dashboard that enables management and sales teams to monitor sales, profit, quantity, products, categories, payment methods, and sales types in order to make data-driven business decisions.

📊 Power BI Sales Dashboard Project | From Data Cleaning to Interactive Dashboard

I’m excited to share my latest Sales Dashboard project built using Microsoft Power BI! 🚀
This project helped me strengthen my data analytics skills by transforming raw sales data into meaningful business insights, starting with data cleaning and ending with an interactive dashboard.

🔍 Project Workflow:

✅ 1. Data Cleaning and Preparation
Cleaned and prepared the raw dataset, checked data quality, and organized the data for analysis.

✅ 2. Data Transformation 
Used Power Query to transform the data and prepare it for accurate analysis and visualization.

✅ 3. Data Analysis 
Analysed sales performance, profit, quantity sold, product performance, sales categories, payment methods, and sale types.

✅ 4. Dashboard Development 
Designed an interactive Power BI dashboard with KPI cards, slicers, bar charts, line charts, donut charts, and a tree map to make the insights easy to understand.

🎯 What I Learned:
This project improved my understanding of data cleaning, data transformation, KPI analysis, data visualization, and dashboard design. Most importantly, I learned how to turn raw data into a clear visual story that can support business decision-making.
